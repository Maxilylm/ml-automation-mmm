The `sigma` column in the lift test DataFrame controls how strongly the experiment evidence pulls the posterior.

**Selection guide:**

| Experiment quality | sigma formula | Notes |
|---|---|---|
| Well-powered geo-lift (narrow CI, ≥ 10% market coverage) | `0.15 × delta_y` | High trust |
| Standard geo-lift | `0.20 × delta_y` | **Default** |
| Wide CI or low market coverage (< 10%) | `(upper_CI - lower_CI) / 3.29` | Map 99% CI → sigma |
| Very noisy / pilot experiment | `0.40 × delta_y` | Use as soft guidance only |
| **Minimum (never below)** | `0.10 × delta_y` | Avoid over-confidence |

**Post-calibration check:**
```python
# Posterior iROAS should be within 15% of experiment estimate
posterior_roas = idata.posterior["iROAS_channel"].mean().item()
experiment_roas = delta_y / delta_x
print(abs(posterior_roas - experiment_roas) / experiment_roas)  # < 0.15 target
```

**When calibration conflicts with data likelihood (posterior drifts far from experiment):**
1. Check spend column maps correctly to the experiment period.
2. Check `delta_y` represents incremental revenue (not total), in the same units as the model target.
3. Widen `sigma` — don't force tight calibration if data genuinely contradicts it.
