`MMM.add_lift_test_measurements()` is the primary calibration method. It adds a likelihood penalty anchoring channel contribution posteriors toward experiment-measured iROAS.

```python
import pandas as pd

df_lift = pd.DataFrame({
    "channel": ["paid_search"],
    "x":       [100_000],        # spend level during experiment
    "delta_x": [10_000],         # incremental spend tested
    "delta_y":  [25_000],         # measured incremental revenue
    "sigma":    [5_000],          # uncertainty on delta_y measurement
})

# Call BEFORE sampling:
mmm.add_lift_test_measurements(df_lift)

with mmm.model:
    idata = pm.sample(...)
```

**DataFrame columns:**
- `channel`: channel name (must match `channel_columns`)
- `x`: baseline spend level during test
- `delta_x`: incremental spend tested
- `delta_y`: measured incremental response
- `sigma`: standard deviation of the measurement uncertainty

**sigma guidance:** Set to `0.2 * delta_y` (20% of measured lift) for a well-powered geo-lift. Widen for noisy experiments. Never set sigma = 0 (overconfident; will conflict with data likelihood).

**Under the hood:** Evaluates the model's saturation function at `x + delta_x` vs `x`, comparing predicted lift to `delta_y`. Adds a Normal likelihood penalty.
