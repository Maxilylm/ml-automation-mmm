`HillSaturation` models the classic S-curve: slow initial response, rapid growth, then diminishing returns. Parameterised by `slope` (steepness), `kappa` (half-saturation point), and `beta` (scale).

**Function:** `beta * hill_function(x, slope, kappa)` where `hill_function(x, s, k) = x^s / (k^s + x^s)`.

**Default priors:** `slope ~ HalfNormal(1.5)`, `kappa ~ HalfNormal(1.5)`, `beta ~ HalfNormal(1.5)`.

**Instantiation:**
```python
from pymc_marketing.mmm.components.saturation import HillSaturation
sat = HillSaturation()

# Tighter kappa prior anchored to observed median spend (normalised = ~0.5):
from pymc_extras.prior import Prior
sat = HillSaturation(priors={
    "kappa": Prior("HalfNormal", sigma=0.5),   # half-sat near median spend
    "slope": Prior("Gamma", mu=3, sigma=1),     # moderately steep
    "beta":  Prior("HalfNormal", sigma=1),
})
```

**Vs LogisticSaturation:** Hill is more interpretable (kappa = spend level at 50% of max response) but has 3 parameters vs 2 for Logistic. Use Hill when a half-saturation point is theoretically meaningful. Use Logistic for simpler, faster models.

**Pitfall:** Wide kappa prior allows kappa >> observed spend range, making the curve look nearly linear. Always anchor kappa prior to observed spend distribution.
