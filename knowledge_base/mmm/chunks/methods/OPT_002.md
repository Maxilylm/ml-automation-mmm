When using `analyze_revenue_vs_spend_levels()` curves instead of the built-in wrapper:

```python
from scipy.optimize import minimize
from scipy.interpolate import interp1d
import numpy as np

# Build interpolators from response curves
interpolators = {}
for ch in paid_channels:
    spends   = [curves['channels'][ch]['multipliers'][m]['spend_level']  for m in multipliers]
    revenues = [curves['channels'][ch]['multipliers'][m]['mean_revenue'] for m in multipliers]
    interpolators[ch] = interp1d(spends, revenues, kind='cubic', fill_value="extrapolate")

def total_revenue(x):
    return -sum(interpolators[ch](xi) for ch, xi in zip(paid_channels, x))

total_budget = 10_000_000
current_spend = np.array([df[ch].mean() * 52 for ch in paid_channels])

result = minimize(
    total_revenue,
    x0=current_spend,
    method="SLSQP",
    bounds=[(current_spend[i] * 0.2, current_spend[i] * 2.0) for i in range(len(paid_channels))],
    constraints={"type": "eq", "fun": lambda x: x.sum() - total_budget},
)
optimal_alloc = dict(zip(paid_channels, result.x))
```

**Bounds:** Always cap upper bound at `1.5–2.0× max observed spend` per channel. Never extrapolate response curve beyond data range.

**Sensitivity table:** Re-run at ±10%, ±20% total budget to produce a sensitivity table for the deliverable.
