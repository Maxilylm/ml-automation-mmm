Full list of available saturation transforms in `pymc_marketing.mmm.components.saturation`:

| Class | lookup_name | Parameters | Best for |
|---|---|---|---|
| `LogisticSaturation` | `logistic` | lam, beta | Default; symmetric S-curve |
| `HillSaturation` | `hill` | slope, kappa, beta | Interpretable half-sat point |
| `HillSaturationSigmoid` | `hill_sigmoid` | sigma, beta, lam | Hill variant for sigmoid shape |
| `MichaelisMentenSaturation` | `michaelis_menten` | alpha, lam | Biochemistry-inspired; similar to Hill |
| `TanhSaturation` | `tanh` | b, c | Simple diminishing returns |
| `TanhSaturationBaselined` | `tanh_baselined` | x0, gain, r, beta | When baseline spend level matters |
| `RootSaturation` | `root` | alpha, beta | Power-law response (alpha ∈ (0,1)) |
| `InverseScaledLogisticSaturation` | `inverse_scaled_logistic` | lam, beta | Alternative to logistic |
| `NoSaturation` | `no_saturation` | beta | Linear response only |

**Default for most projects:** `LogisticSaturation` or `HillSaturation`. Benchmark both in prior predictive; pick the one with better prior coverage over plausible response curves.

**Serialisation:** Classes are identified by `lookup_name` in YAML config. Use the lookup_name string to specify transforms in config files.
