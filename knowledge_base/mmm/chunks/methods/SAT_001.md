`LogisticSaturation` is the default saturation transform. It applies a symmetric S-curve, controlled by `lam` (compression strength) and `beta` (scale/amplitude).

**Function:** `beta * logistic_saturation(x, lam)` where `logistic_saturation(x, lam) = (1 - exp(-lam*x)) / (1 + exp(-lam*x))`.

**Default priors:** `lam ~ Gamma(alpha=3, beta=1)` (mean=3), `beta ~ HalfNormal(sigma=2)`.

**Instantiation:**
```python
from pymc_marketing.mmm.components.saturation import LogisticSaturation
sat = LogisticSaturation()

# Hierarchical lam across geos:
from pymc_extras.prior import Prior
hierarchical_lam = Prior("Gamma", alpha=Prior("HalfNormal"), beta=Prior("HalfNormal"), dims="channel")
sat = LogisticSaturation(priors={"lam": hierarchical_lam, "beta": Prior("HalfNormal", dims="channel")})
```

**Identification rule:** If a channel has < 3 distinct spend levels or CV < 0.05, use `NoSaturation` instead — saturation cannot be identified and lam will absorb noise.

**Burst/intermittent channels:** If a channel has > 30% zero weeks, flag as burst spend. If > 50% zero weeks, strongly prefer `NoSaturation` — the saturation curve cannot be identified when inputs are mostly zero, even when CV appears high. A channel with CV=1.9 and 55% zero weeks will still produce catastrophic divergences (R-hat > 3) with LogisticSaturation. See SAT_004.

**Prior sensitivity:** If posterior `lam` hits 0, the channel is nearly linear — consider `NoSaturation`. If `lam` is very large (> 20), the channel saturates immediately — check spend scale and normalization.
