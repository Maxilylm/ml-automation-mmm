Channels with burst/intermittent spend (many zero-spend weeks) can cause `LogisticSaturation` to diverge because `lam` is identified from the shape of the non-zero spend distribution. The zero-rate alone is not sufficient to determine whether identifiability will fail — what matters is **variation within the non-zero portion** and **cross-channel burst correlation**.

**Detection:**
```python
zero_rate  = (df[channel_cols] == 0).mean()
cv_nonzero = df[channel_cols].replace(0, np.nan).std() / df[channel_cols].replace(0, np.nan).mean()
n_distinct = df[channel_cols].apply(lambda c: c[c > 0].nunique())
burst_corr = (df[channel_cols] == 0).corr()  # off-diagonal ≥ 0.7 → correlated burst
```

**Decision table (per channel):**

| Zero-week rate | cv_nonzero (non-zero weeks only) | n_distinct_nonzero | Decision |
|---|---|---|---|
| < 30% | any | any | LogisticSaturation (default) |
| 30–50% | ≥ 0.5 and ≥ 50 distinct values | ≥ 50 | LogisticSaturation; flag for monitoring |
| 30–50% | < 0.5 or < 50 distinct values | < 50 | NoSaturation |
| > 50% | any | any | **NoSaturation** — run both variants and compare holdout MAPE if identification is uncertain |

**Second failure mode — correlated burst patterns:**
Even when individual channels pass the cv/distinct thresholds, `LogisticSaturation` can produce poor attribution if ≥ 2 channels share burst weeks (pairwise zero-week correlation ≥ 0.7). In that case, the model cannot distinguish which channel drove spend in active periods. Apply `NoSaturation` globally when this condition holds.

**Implementation note (pymc-marketing 0.18.2):** The standard `MMM` class applies a single saturation type to all channels. When any channel requires `NoSaturation`, apply it globally — per-channel mixed saturation requires the lower-level `MMMModel` API.

**Global override trigger:** Apply `NoSaturation` globally if:
- any channel has zero_rate > 50%, OR
- ≥ 2 channels have pairwise burst correlation ≥ 0.7

**Evidence base:**

| Dataset | Burst channels | cv_nonzero | LogisticSat result | NoSaturation result | Conclusion |
|---|---|---|---|---|---|
| Robyn simulated | 4 (TV/OOH/Print/FB), 50–59% zeros | low (few distinct levels) | 754 divergences, R-hat 4.0 | 0 divergences | NoSaturation correct |

**Practical guidance:** When in doubt, run both variants and compare holdout MAPE and beta recovery against any available ground truth. The zero-rate threshold alone is not a reliable single criterion.
