`MultiDimensionalBudgetOptimizerWrapper` optimises budget allocation across channels (and optional geo/brand dims) to maximise expected KPI from a fitted MMM.

```python
from pymc_marketing.mmm.multidimensional import MultiDimensionalBudgetOptimizerWrapper
import xarray as xr, numpy as np

wrapper = MultiDimensionalBudgetOptimizerWrapper(
    model=mmm,
    start_date=df["date"].max() + pd.Timedelta(weeks=1),
    end_date=df["date"].max() + pd.Timedelta(weeks=8),
)

optimal, result = wrapper.optimize_budget(
    budget=10_000_000,                          # total budget $
    response_variable="total_media_contribution_original_scale",
)
# optimal: xr.DataArray (channel,) or (channel, geo)
```

**Constraint — select which cells to optimise:**
```python
budgets_to_optimize = xr.DataArray(
    np.array([[True, False], [True, True]]),
    dims=["channel", "geo"],
    coords={"channel": ["C1", "C2"], "geo": ["A", "B"]},
)
optimal, _ = wrapper.optimize_budget(budget=1e6, budgets_to_optimize=budgets_to_optimize)
```

**Optimiser:** Uses scipy SLSQP with an equality constraint (total spend = budget) and per-channel bounds. Objective is the posterior mean response curve — uncertainty in allocation is captured by running optimisation on HDI bounds separately.
