# ml-automation-mmm

Media Mix Modeling. Bayesian MMM with adstock, saturation, channel attribution, budget optimization, and client-ready reporting. Requires spark-core installed.

This plugin's work is tracked in Jira project [PM3](https://blend360.atlassian.net/jira/core/projects/PM3/board). Filter the board by label `plugin:mmm` for this plugin's slice.
